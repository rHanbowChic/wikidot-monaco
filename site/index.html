特性Features

页面编辑、论坛发帖、查看源代码和页面历史，都换成同一个编辑器。 Page editing, forum posts, page source and page history all use the same editor.

语法高亮Syntax highlighting

标题、标签、属性、链接、ListPages 变量各有颜色；[[module CSS]] 和 [[html]] 块内按 CSS / HTML 高亮。 Headings, tags, attributes, links and ListPages variables in their own colors; CSS and HTML highlighting inside [[module CSS]] and [[html]].

自动补全Autocomplete

补全标签、属性、模块和 ListPages 变量，补全 [[div]] 时自动加上 [[/div]]。 Completes tags, attributes, modules and ListPages variables, and adds [[/div]] when completing [[div]].

悬停说明Hover docs

鼠标停在标签、模块、属性或变量上，就能看到它的用法。 Rest the pointer on a tag, module, attribute or variable to see how it is used.

页面跳转Page links

按住 Ctrl 点击 [[include ...]]、[[[页面]]] 中的页面名，在新标签页打开。 Ctrl+click the page in [[include ...]] or [[[page]]] to open it in a new tab.

版本比较Revision diffs

页面历史的「源代码变更」以带高亮的左右对比显示，未改动部分自动折叠；手机上可改为内联。 Source changes in page history are shown side by side with highlighting, unchanged parts folded; switch to inline on phones.

保存超时Save timeout

网络不好时，保存不再一直卡在「Saving page...」：超时后提示失败，可以直接再存一次。 On a bad connection saving no longer hangs on “Saving page...”: after a timeout you get an error and can save again.

兼容原有工具Keeps your tools working

原文本框仍在页面中，读写都转给编辑器；wikidot 的编辑工具栏和社区插件照常工作。 The original textarea stays on the page and reads and writes the editor, so the wikidot toolbar and community scripts keep working.

随时切换回去Switch back anytime

右键菜单「切换到纯文本框」，再点 −/+ 旁的「Monaco」即可切回，内容与选区都保留。 “Switch to Plain Textarea” in the context menu; the “Monaco” button next to −/+ brings the editor back, with text and selection kept.

离线、按需加载Offline, on demand

Monaco 完整打包在扩展内，不请求任何 CDN；页面上出现编辑框时才加载。 Monaco is bundled in the extension with no CDN requests, and loads only when an edit box appears.

按自己的习惯调整Make it yours

主题、字号、行高、换行、行号、缩略图、补全方式……设置在各设备间同步，改完立即生效。也可以在编辑器里右键打开设置页。 Theme, font size, line height, word wrap, line numbers, minimap, how suggestions show up… Settings sync across devices and apply right away. Right-click in the editor to open them.

  • 标签内回车自动闭合并缩进Enter in tags closes them and indents

手动安装Install manually

GitHub Releases 提供的是未经 Mozilla 签名的 .zip，Firefox 正式版只能临时载入，重启后失效；Developer Edition、Nightly 与 ESR 可以长期安装。GitHub Releases has an unsigned .zip. Release Firefox only loads it until the next restart; Developer Edition, Nightly and ESR can keep it installed.

  1. 在 GitHub Releases 下载 -firefox.zipDownload the -firefox.zip from GitHub Releases
  2. 临时载入：打开 about:debugging 的「此 Firefox」页，点「临时载入附加组件」并选择该 .zipTo load it until restart: open “This Firefox” in about:debugging, click “Load Temporary Add-on” and choose the .zip
  3. 长期安装（Developer Edition、Nightly、ESR）：在 about:config 把 xpinstall.signatures.required 设为 false，将文件扩展名改为 .xpi，再在 about:addons 中「从文件安装附加组件」To keep it (Developer Edition, Nightly, ESR): set xpinstall.signatures.required to false in about:config, rename the file to .xpi, then use “Install Add-on From File” in about:addons

从源码构建Build from source

需要 Git 与 Node.js 20 或更新版本（含 npm），Linux、macOS、Windows 均可，不需要其他全局安装的工具。Requires Git and Node.js 20 or later (with npm). Works on Linux, macOS and Windows; no other global tools are needed.

1. 获取源码与依赖1. Get the source and dependencies 

$ git clone https://github.com/rHanbowChic/wikidot-monaco
$ cd wikidot-monaco
$ npm ci

npm ci 按 package-lock.json 安装锁定版本的依赖。Monaco 编辑器是 npm 依赖，会完整打包进扩展，运行时不访问任何 CDN。npm ci installs the exact versions in package-lock.json. Monaco is an npm dependency bundled into the extension; nothing is loaded from a CDN at run time.

2. 构建2. Build

$ npm run build          # Chrome  → build/
$ npm run build:firefox  # Firefox → build-firefox/

两个命令都先运行 tsc 做类型检查（不输出文件），再由 scripts/build.mjs 调用 Vite，分别构建设置页、后台脚本、两个内容脚本与按需加载的编辑器模块。两个版本源码相同，只有 manifest 在构建时转换：background.service_worker 换成 background.scripts，并加上 browser_specific_settings.gecko。版本号取自 package.json。Both run tsc for type checking only, then scripts/build.mjs runs Vite for the options page, the background script, the two content scripts and the editor module that loads on demand. The source is shared; only the manifest is converted for Firefox: background.service_worker becomes background.scripts and browser_specific_settings.gecko is added. The version comes from package.json.

3. 载入浏览器3. Load it

  • Chrome / Edge：在 chrome://extensions 开启「开发者模式」，点「加载已解压的扩展程序」，选择 build/。Chrome / Edge: turn on Developer mode in chrome://extensions, click “Load unpacked” and choose build/.
  • Firefox：在 about:debugging 的「此 Firefox」页点「临时载入附加组件」，选择 build-firefox/manifest.json。Firefox: in “This Firefox” under about:debugging, click “Load Temporary Add-on” and choose build-firefox/manifest.json.

4. 开发4. Develop

$ npm run dev          # watch → build/
$ npm run dev:firefox  # watch → build-firefox/
$ npm run run:firefox  # Firefox with a temporary profile

dev 监听源码并在修改后重新构建，之后需在扩展页重新载入扩展并刷新 wikidot 页面。run:firefox 用临时配置启动 Firefox 并载入 build-firefox/，文件变化时自动重载，可与 dev:firefox 同时运行。dev rebuilds on every change; reload the extension on the extensions page and refresh the wikidot page afterwards. run:firefox starts Firefox with a temporary profile, loads build-firefox/ and reloads it when files change; run it alongside dev:firefox.
